# AURA — Data Art Studio

A generative art tool that transforms CSV data into expressive compositions made from particles, waves, glass, terrains, and abstract forms.

## Live site

GitHub Pages publishes the lightweight standalone browser edition from `github-pages/`.

## External controller

- `Q` selects a different built-in dataset.
- `W` selects a different visual language.
- `E` selects a different color harmony.
- `R` cycles the knob target through density, energy, and flow.
- Knob left/right (arrow keys or mouse wheel) decreases/increases the selected parameter.
- `A` is an alternate increase control for keyboard firmware that emits it.

The original vinext/React implementation is included in the downloadable source archive. The standalone edition has no server or framework dependency and is optimized for GitHub Pages.
